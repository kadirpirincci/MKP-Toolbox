# MKP Toolbox

A Python-based electrical engineering calculation tool developed for learning Python programming and assisting with common electrical engineering calculations.

> **Current Version:** v0.1.0

---

## Features

The current version includes the following calculation modules:

- ⚡ Power Calculation
- ⚡ Ohm's Law
- ⚡ Energy Consumption
- ⚡ Three-Phase Calculations
- ⚡ Voltage Drop Calculation

---

## Installation

Install the test dependency:

```bash
python -m pip install pytest
```

Clone the repository:

```bash
git clone https://github.com/kadirpirincci/MKP-Toolbox.git
```

Go to the project directory:

```bash
cd MKP-Toolbox
```

---

## Usage

Run the application:

```bash
python main.py
```

---

## Running Tests

Execute all unit tests:

```bash
pytest
```
